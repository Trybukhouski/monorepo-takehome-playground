# Лендинг «Экскурсии в Брест»

Адаптивный одностраничный сайт (лендинг) с расписанием экскурсий и отзывами клиентов. Проект выполнен в рамках тестового задания.

👉 **[Ссылка на живой сайт / GitHub Pages](https://github.io)**

---

## 🛠 Технологии и инструменты

При разработке проекта использовались только разрешенные ТЗ инструменты:

- **Разметка:** Семантический HTML5.
- **Стили:** SCSS (методология БЭМ, архитектура 7-1).
- **Скрипты:** Нативный JavaScript (ES6+), без использования jQuery.
- **Сборщик:** Vite (для быстрой сборки, минификации кода и компиляции SCSS).
- **Библиотеки:** [Name] — для удобного выбора дат в календаре.

_Использование CSS-фреймворков (Bootstrap, Tailwind) или UI-библиотек умышленно исключено согласно требованиям задания._

---

## 📱 Функционал и особенности проекта

1.  **Полная адаптивность:**
    - Вёрстка корректно отображается на смартфонах (от 360px), планшетах (от 768px) и десктопах (от 1024px).
2.  **Интерактивность на Native JS:**
    - Реализовано отзывчивое мобильное бургер-меню (с блокировкой скролла страницы при открытии).
    - Плавный скролл к блоку с расписанием при клике на кнопку «Расписание».
    - Самостоятельно написанный слайдер для просмотра отзывов клиентов.
    - Базовая валидация и обработка формы поиска без перезагрузки страницы.
3.  **Внимание к деталям:**
    - Реализованы плавные hover/focus состояния для всех интерактивных элементов (кнопок, инпутов, ссылок); соблюдены уникальные состояния карточек (например, заглушка для карточки «Нет мест»).
